## 📊 Modules Breakdown & Interview Speaking Points

During your interviews, you can present this project as a **Decoupled microservice-ready system** utilizing high-performance API structures and an advanced data-driven frontend. Here is how each MVP requirement fits:

### 1. Intelligent Scheduler (Core Python & Logic)
- **What it does**: Dynamically optimizes your daily routine based on your upskilling priorities.
- **Under the Hood**: Uses mathematical slot-filling rules to allocate focus hours.
- **Talking Point**: *"I built a custom priority-scheduler that models study blocks dynamically. It parses student inputs, evaluates urgency, and balances technical coding practice with soft-skills prep."*

### 2. AI Career Coach (Generative AI & Software Patterns)
- **What it does**: Provides technical mock interviews, grades written code, and gives real-time reviews.
- **Under the Hood**: Prompt engineering with structured JSON outputs, utilizing FastAPI background tasks to avoid locking UI threads during AI evaluations.
- **Talking Point**: *"I integrated generative models to perform real-time code reviews. To optimize latency and improve UX, I handled payload validation with Pydantic and designed structured JSON output schemas."*

### 3. Personal Trainer (Data Analytics & Visualization)
- **What it does**: Tracks daily habit consistency, productivity levels, and learning curves.
- **Under the Hood**: Employs pandas/numpy on the backend to aggregate habit logs, calculating consistency indexes to serve as charts in React.
- **Talking Point**: *"I built a habit-telemetry system where client-side metrics are aggregated on the backend using Pandas. I computed a rolling standard deviation of study duration to track focus consistency."*
