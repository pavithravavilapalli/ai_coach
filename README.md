# Personalized AI Life & Career Coach

An intelligent self-mentorship and productivity hub tailored for master Python Full Stack,
Data Analytics, and AI Full Stack domains.

## Tech Stack
- **Backend**: FastAPI (Python), Uvicorn, SQLAlchemy (SQLite/PostgreSQL)
- **Frontend**: React (TypeScript, Vite, Tailwind CSS)
- **AI/ML Layer**: OpenAI API & Google Gemini API, Pandas/NumPy/Scikit-Learn

## Getting Started
1. Run `python setup_project.py` to verify or regenerate the structure.
2. Set up Python virtual environment in `backend/` and install dependencies.
